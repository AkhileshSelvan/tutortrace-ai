# Original educational sample assets

`energy_notes.pdf` (2 pages) and `energy_slides.pptx` (2 slides) contain short,
self-created explanations of energy and power. They contain no student data and
were not copied from another repository or course. The source text and generator
are in `scripts/create_demo_assets.py`; content was drafted with Codex assistance.

These sample texts and generated sample files are dedicated to the public domain
under CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/.
This dedication covers the demo assets only, not third-party libraries.

Regenerate from the repository root with:

```powershell
.\.venv\Scripts\python.exe -m scripts.create_demo_assets
```

Document IDs hash the actual file bytes. Regenerated PowerPoint ZIP metadata can
change the byte hash even when slide text is unchanged. Byte-identical reuploads
are duplicates; semantic duplicates are not detected.
